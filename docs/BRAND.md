# Yunima identity

The mark combines a rounded **Y** with a **play** triangle cut into its right arm. The shared stem connects creation and playback. Rounded contours echo the approachable editor; violet preserves the product's established palette.

## Assets

- `public/brand/yunima-mark.svg`: transparent vector master.
- `public/brand/yunima-logo.svg`: outlined wordmark for dark backgrounds, used in the editor header.
- `public/brand/yunima-logo-light.svg`: outlined wordmark for light backgrounds.
- `public/brand/yunima-mark-mono.svg`: single-color mark for print and restricted-color use.
- `public/brand/yunima-mark.png`: transparent 1024 × 1024 mark.
- `public/brand/yunima-app-icon.{svg,png}`: dark rounded tile; PNG is 512 × 512.
- `public/favicon.svg`, `public/favicon-32.png`, `public/apple-touch-icon.png`: browser and home-screen icons.

The wordmark is outlined from Arial Rounded MT Bold; no font file, external font request or installed font is required to display the SVG. All SVG artwork is static and self-contained.

## Palette and use

| Role | Color |
| --- | --- |
| Light violet | `#E3D8FF` |
| Primary violet | `#BBA4FF` |
| Deep violet | `#946BEA` |
| Dark tile | `#231D32` |
| Light wordmark | `#F3EFFA` |
| Dark wordmark | `#292235` |

Use the mark at 20 px or larger when possible. The dedicated favicon tile is available for smaller sizes. Keep at least one-quarter of the mark's width clear around it. Preserve proportions, the triangular counter and the fixed wordmark spacing. Use the light-background variant on white; use the primary variant on the editor's dark surface. Do not animate the logo automatically inside the editor.
